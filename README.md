# 토토네 과외

아이폰 홈 화면에서 여는 과외 시간표 앱이에요.

- **화면**: 이 저장소를 GitHub Pages로 보여줘요.
- **데이터**: 구글 스크립트가 시간표 시트를 읽기 전용으로 읽어서 보내 줘요. 연결 코드가 있어야만 받을 수 있고, 코드와 수업 데이터는 이 저장소에 없어요.
- **번 돈**: 시트의 요금표(J열 시간당 요금, K열 이름, 만원 단위)로 수업마다 번 돈을 셈해서 시간표 아래에 '오늘 번 돈'과 '이번 달 누적'을 보여줘요. '오늘 번 돈'을 누르면 '날짜별 번 돈'이 열려서 달 → 날짜 → 수업(시각·학생·금액) 순서로 접고 펼 수 있어요. '이번 달 누적'을 누르면 '번 돈 장부'가 열려서 달 → 학생 → 수업(날짜·시각·금액) 순서로 볼 수 있어요. 시트 탭은 주마다 새로 바뀌니까, 지나간 날은 구글 스크립트가 자기 저장소에 장부로 옮겨 적어 둬요(시트에는 아무것도 쓰지 않아요). 토토 대사에는 돈 얘기를 넣지 않아요.

언제 무엇을 바꿨는지, 다음에 어디서부터 고치면 되는지는 [HANDOFF.md](HANDOFF.md)에 적어 뒀어요.

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 화면 전체 (디자인, 시간과 번 돈 계산, 데이터 가져오기) |
| `manifest.webmanifest` | 홈 화면 앱 이름과 아이콘 |
| `icons/`, `toto.jpg` | 토토 아이콘과 그림 |
| `HANDOFF.md` | 구조, 시트 규칙, 작업 기록, 이어서 고치는 법 |
| `CLAUDE.md` | Claude가 이 저장소에서 작업할 때 지킬 것 |
