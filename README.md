# 토토네 과외

아이폰 홈 화면에서 여는 과외 시간표 앱이에요.

- **화면**: 이 저장소를 GitHub Pages로 보여줘요.
- **데이터**: 구글 스크립트가 시간표 시트를 읽기 전용으로 읽어서 보내 줘요. 연결 코드가 있어야만 받을 수 있고, 코드와 수업 데이터는 이 저장소에 없어요.

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 화면 전체 (디자인, 시간 계산, 데이터 가져오기) |
| `manifest.webmanifest` | 홈 화면 앱 이름과 아이콘 |
| `icons/`, `toto.jpg` | 토토 아이콘과 그림 |
